## Lab Questions

### In plain English describe the function and use of a multiplexer.
Allows selection of an input to give to output via a switch, and can be used for many things like network switches, which require selection of specific inputs.

### In plain English describe the function and use of a demultiplexer.
Allows for a single input to be decrypted to one of several outputs, one use is for vending machines, where you enter one code to select one of several outputs.

### What other uses might these circuits have? (Think Shannon’s)
You can build any other type of logic circuit using multiplexers to reduce material costs. Our FPGAs are one example of a piece of hardware using only multiplexers.
